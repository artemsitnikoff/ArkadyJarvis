# ArkadyJarvis — AI-ассистент всей команды в одном Telegram-боте

Корпоративный бот, который заменяет 10+ переключений между системами на одну кнопку. Вся команда работает из Telegram — встречи, задачи, лиды, документы, найм, юрист, офис-менеджер.

---

## 🧩 Что внутри

### 🗓 Календарь и команда
- **Старт рабочего дня** одной кнопкой → Bitrix24 timeman + персональное AI-приветствие
- **Моя команда** — вся команда со статусом «работает / пауза / не начал»
- **Встреча** — создание встреч с поиском участников по имени
- **Найди время** — слоты 5 рабочих дней по календарям всех участников
- **Мои встречи** — сегодняшние встречи со ссылками в Bitrix

### 📝 Работа с тикетами и клиентами
- **Задача в Jira** — пишешь сумбурно, AI переформулирует по шаблону (Задача / Контекст / Что сделать / Блокеры / Результат), создаёт тикет
- **Лид в Bitrix CRM** — AI сам извлечёт имя, компанию, телефон, email из свободного текста
- **Сотрудник** — мгновенная карточка по базе Bitrix

### ⚖️ Документы и юриспруденция
- **Проверь договор** — загружаешь PDF/DOCX, AI сверяет по чек-листу компании (реквизиты, НДС, условия приёмки) за 30 секунд
- **Цицерон — AI-юрист** — консультации по ГК, КоАП, АПК, НК РФ со ссылками на КонсультантПлюс. Присылаешь документ → получаешь черновик жалобы/претензии/отзыва

### 👔 Найм и бэк-офис
- **Анатолий — AI-рекрутёр** — интеграция с Potok.io: оценивает резюме по вакансии, ставит балл 0–100, пишет комментарий в ATS. **100 кандидатов за час вместо 2 дней**
- **Глафира — AI офис-менеджер** — через браузер-RPA заказывает, бронирует, заполняет формы голосом

### 📊 Коммуникации
- **Суммаризация чатов** — ежедневный обзор дня в 19:00 в ЛС по всем корпоративным чатам с задачами, решениями, неотвеченными вопросами
- **Картинка** — генерация визуала через Gemini 3 Pro Image
- **Спроси AI** — Claude Opus 4.7 в Telegram

## 🎯 Для кого
Компании 20–200 человек, у которых уже есть **Bitrix24 + Jira + Telegram**, и которые устали платить за десять разных SaaS. ArkadyJarvis — это один бот, который склеивает всё, что у вас уже есть, и добавляет сверху AI-слой.

## 🔐 Под капотом
Claude Opus 4.7, Gemini 3 Pro Image, Bitrix24 REST API, Jira REST API, Potok.io, OpenClaw (браузер-RPA). Развёртывание on-premise через Docker — данные не покидают контур компании.
