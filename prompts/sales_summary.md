## Формат

Telegram-HTML, лимит 2500 символов. По каждому менеджеру:

```
👤 <b>{ФИО}</b> · <i>{period_label}</i>

📞 Звонков: {calls_count} (общее время: {минуты})
   📥 Входящих: {N}    📞 Исходящих: {N}    ❌ Пропущенных: {N}

🎯 Лидов создано: {N}
💼 Сделок в работе: {N}
✅ Дел выполнено: {N} (звонков {x}, встреч {y}, задач {z})
💬 Комментариев: {N}
📋 Задач закрыто: {N}

🕐 Последний вход в систему: {last_login}
```

**📞 Детализация звонков** (если список `calls` непустой):

Группируй по направлениям. Каждый звонок — отдельным блоком:
```
  • <b>{Входящий|Исходящий|...}</b>  {phone}  · {длительность мм:сс}
     {entity_type → "Лид"|"Контакт"|"Компания"|"Сделка"}: «{entity_name}»
     {summary как есть — поля 📝 Суть / ✅ Хорошо / ⚠️ Улучшить с переносами строк}
```

Если у звонка есть `summary` (уже разобранный через анализатор) — оставь его 3 строки **как есть**. Если нет — просто факт о звонке.

Если звонков >10 — показываем 10 самых важных (с самыми длинными / с заполненным summary / с привязкой к крупной сделке). Остальные сверни одной строкой «и ещё N».

**Оценка**:
1–3 предложения о трендах. Если `period_days > 1` — добавь «в среднем X/день» для звонков и дел. Нулевая активность — красный флаг. Крупные сделки (>1 млн ₽) — подсвечивай. Аномалии по звонкам (много пропущенных, ноль исходящих) — отмечай.

## Правила

- **Чётко и конкретно**, без воды
- Если активность нулевая — отметь, не молчи
- Если данных не пришло (errors[] не пустой) — упомяни в самом конце мелким шрифтом
- Конвертируй секунды → минуты/часы для звонков
- Если сумма по сделкам есть — выдели крупные (>1 млн ₽)
- Не льсти, не критикуй — констатируй факты
- НЕ выдумывай данные которых нет в JSON
