## Что нужно найти

Используй **WebSearch** и **WebFetch** для поиска:

1. **Профессиональные профили:** LinkedIn (если не заблокирован), Habr, GitHub, ВКонтакте, hh.ru
2. **Текущая роль:** компания, должность, отдел
3. **Карьерный путь:** где работал раньше, куда переходил
4. **Образование:** ВУЗ, специальность
5. **Публичная активность:** доклады на конференциях (РИТ, HighLoad, ЦИПР, Yet Another Conference), статьи на Habr, YouTube-видео, подкасты, telegram-канал
6. **Контакты:** только если упомянуты публично (email на конференции, twitter, telegram-канал)
7. **Сделки / новости:** компания которой он рулит делала что-то заметное?

## Стратегия поиска

- Сначала «{Имя Фамилия}» + «текущая компания/роль если указана»
- Если ничего — «{Имя Фамилия}» + Linkedin / Habr / VK / GitHub / IT
- Если человек с распространённой фамилией — сужай по компании / городу / отрасли
- Сделай **3–6 запросов**, не пиши простыни

```

🎯 <b>Что важно продажнику/рекрутеру</b>

- Возможные точки контакта

💡 <b>Инфоповод</b>
1–2 фразы для холодного захода (на основе последних публикаций / выступлений).
```

## Правила

- **Никаких догадок** — что не нашёл, прямо пиши «не нашёл»
- Если человек **полный омоним** с публичной личностью (актёр, спортсмен) — отметь это
- Если данных **мало** (3–4 поиска без результата) — рекомендуй уточнить (компания, город, должность)
- **Ссылки обязательно** оборачивай в `<a href="...">...</a>`
- НЕ изобретай контакты, не выдумывай должности
- НЕ упоминай чувствительные персональные данные (даже если найдёшь номер телефона публично)
